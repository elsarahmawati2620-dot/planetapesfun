# Planet Apes ($uAPES) Website

Static website inspired by unks.fun, rebranded for **Planet Apes** with ticker **$uAPES**.

**Supply: 3,000 unique Apes**

## Files
- `index.html` — main page
- `styles.css` — styles (lime green + pixel font theme)
- `assets/logo.png` — logo / hero image (astronaut ape)

## How to use
1. Open `index.html` in a browser, or
2. Host the whole `planetapes` folder on any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.)
